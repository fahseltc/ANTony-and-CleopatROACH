# Changelog

## V2

A round of polish and fixes since the original release.

### New
- Roach hives can now train roaches, just like ant hives train ants. Select a
  roach hive to bring up its build options.
- The roach hive's train button now shows a roach and its own cost.
- Workers can be set to start gathering a specific resource right from the
  start of a level.
- The multi-hive tutorial now guides you through the steps properly and moves
  on once you've done each one.

### Improved
- Long pop-up messages now wrap onto multiple lines instead of running off the
  screen.
- Finishing the last level now takes you back to the main menu instead of
  getting stuck on a blank level.

### Fixed
- Workers no longer gather from too far away — they walk right up to the
  resource before harvesting.
- Button tooltips now line up with the correct button, including the ones along
  the bottom row.
- The unit hotkey buttons now hide along with the rest of the interface during
  cutscenes.
- The roach hive no longer shows a build option it can't actually use.
- Fixed a cutscene where a character wouldn't move as intended.

## V1

The original game jam release.

Lead a swarm of ants across the desert: select workers and send them to gather
sucrose and wood, spend resources at your hive to grow your swarm, and build
bridges across water so Antony the ant can reunite with Cleopatroach. Each level
is complete when the two royals meet. Features fog of war, a minimap, camera
controls, unit groups, story cutscenes, and per-level intros and tutorials.
